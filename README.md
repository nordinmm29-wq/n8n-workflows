# n8n-workflows
# 🤖 n8n Automations & AI Agents

A curated collection of ready-to-use **n8n workflows** and **reusable templates** focused on API and service integrations. Designed to help you automate repetitive tasks and connect your favorite tools without writing a single line of code.

## ✨ What's inside

- **📦 Ready-to-use workflows** — Import and run in minutes, no setup headaches
- **🔌 API & service integrations** — Connectors for popular platforms (OpenAI, Slack, Notion, Google, webhooks, and more)
- **♻️ Reusable templates** — Modular building blocks you can adapt to your own use cases
- **🧩 Composable design** — Workflows built to be combined, extended, and customized

## 🚀 Getting started

1. Clone or download this repository
2. Open your n8n instance
3. Import the `.json` file of the workflow you want
4. Configure your credentials and you're good to go

## 📁 Structure
/workflows       → Full automation flows ready to import
/templates       → Reusable building blocks and sub-workflows
/docs            → Notes, diagrams and usage guides

## 🛠️ Requirements

- [n8n](https://n8n.io/) — self-hosted or cloud
- API keys for the relevant services (documented per workflow)
